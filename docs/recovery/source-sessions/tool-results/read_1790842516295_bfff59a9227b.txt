    57→### 🟡 Pripravljeno, čaka na aktivacijo ponudnika
    58→
    59→- **7 API adapterjev je kodirano-pripravljenih** (Viator, GetYourGuide, Tiqets, Booking,
    60→  Skyscanner, Airalo, Travelpayouts) — vrata so živo preverjena, vsak adapter je priklopljen
    61→  v **iskreno praznem stanju**, dokler poverilnica ni v env. To NI aktivna API integracija.
    62→- **Affiliate plast deluje ŽE DANES brez poverilnic** (fail-closed čiste povezave): vsaka
    63→  `/go/*` preusmeritev vodi na delujočo partnerjevo stran (`monetized: false` — nikoli
    64→  lažnega trackinga); ko poverilnica pride v env, se monetizacija prižge **brez spremembe
    65→  kode**. Načrtovalnik pokriva vseh 9 partnerjev (1.84.0: + Tiqets vstopnice, + zavarovanje
    66→  z `days` iz dolžine načrta).
    67→- **Booking arhitektura** — `JourneyBooking` stanjski model, potrditvena validacija,
    68→  provider-agnostic registracija resolverjev — zamrznjena v stanju „activation ready".
    69→- **Ni še aktivirano:** API booking, webhook ingest ponudnikov, živi citati/rezervacije,
    70→  odpovedi in refundacije.

    72→### Meje, ki jih sistem izrecno ločuje
    73→
    74→- **Odkrivanje ≠ rezervacija** — rezultat iskanja ni potrjena rezervacija.
    75→- **Affiliate preusmeritev ≠ inventar** — globoka povezava ni hotelska/letalska zaloga.
    76→- **Zunanja rezervacija ≠ potrjena rezervacija** — številka rezervacije pomeni
    77→  „Zunanja rezervacija", dokler provider ne vrne svoje.
    78→- **Znana cena ≠ živi citat** — objavljena „od"-cena iz feeda ni potrjena cena ob poizvedbi.
